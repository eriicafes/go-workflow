# into structs and has no older clients to stay wire compatible with.

packages/world/src/attributes.test.ts > applyAttributeChanges > returns a new object (does not mutate input) -- JavaScript object identity of the SDK's applyAttributeChanges helper; Go Worlds apply attribute changes to their own stored run.
packages/world/src/capabilities.test.ts -- the SDK's wire format of a peer World's capabilities, parsed with Zod; a Go World reports worlds.Capabilities, a struct of its own fields, and peers exchange it in CBOR.
packages/world/src/event-metadata.test.ts > event metadata > classifies mutually exclusive entity events -- the SDK's entity event classes for its storage layer; Go has no event classes.
packages/world/src/event-metadata.test.ts > event metadata > identifies sealed-log filler events without loading event schemas -- loading Zod event schemas lazily; Go compares an event's EventType with worlds.EventTypeNoop.
packages/world/src/events.test.ts > dynamic workflow code storage shape -- dynamic workflow code; Go workflows are compiled in.
packages/world/src/events.test.ts > step_started ownerMessageId > accepts an optional ownerMessageId on the create request -- go-workflow's step_started records no ownerMessageId (worlds.DataStepStarted).
packages/world/src/events.test.ts > step_started ownerMessageId > retains ownerMessageId when reading back a stored step_started event (not stripped) -- go-workflow's step_started records no ownerMessageId (worlds.DataStepStarted).
packages/world/src/events.test.ts > sealed-log noop events > parses a noop event from the read union -- Zod's read union of event types; Go reads every event into worlds.Event whatever its type.
packages/world/src/events.test.ts > sealed-log noop events > parses a noop with no eventData at all -- Zod's read union of event types; Go reads every event into worlds.Event whatever its type.
packages/world/src/hooks.test.ts -- Zod parsing of the Hook schema's optional resumeContext, and older clients stripping it; Go decodes hooks into worlds.Hook, whose ResumeContext the conformance suite checks.
packages/world/src/runs.test.ts > WorkflowRunSchema -- Zod's optional output and error fields of terminal runs; worlds.Run holds them as nil-able byte slices.
packages/world/src/runs.test.ts > BulkCancelWorkflowRunsRequestSchema -- bulk run cancellation, which go-workflow does not implement.
packages/world/src/runs.test.ts > BulkCancelWorkflowRunResultSchema -- bulk run cancellation, which go-workflow does not implement.
packages/world/src/runs.test.ts > BulkCancelWorkflowRunsResultSchema -- bulk run cancellation, which go-workflow does not implement.
packages/world/src/shared.test.ts -- caching of compiled Zod page schemas per module copy; Go decodes pages into worlds.Page.
packages/world/src/snapshots.test.ts -- the SDK's workflow VM snapshot envelope; go-workflow replays runs from their event log and stores no snapshots.
packages/world/src/usage.test.ts -- the per-run usage report of the SDK's CLI and web UI (workflow inspect run --usage); go-workflow has no usage report.

# packages/world/src/slot-identity.test.ts
packages/world/src/slot-identity.test.ts > slotToEventId > refuses slots it cannot represent exactly -- JavaScript number checks: a Go slot is a uint64, so a negative, fractional or float-imprecise slot cannot be passed to worlds.EventIDForSlot.
packages/world/src/slot-identity.test.ts > isSlotEventId > reads an id however it is prefixed -- the legacy wevt_ and bare event IDs of older SDK data; go-workflow keeps no compatibility with old data, and worlds.EventSlot reads the evnt_ IDs it mints.

packages/world/src/spec-version.test.ts > spec version constants > mintedSpecVersion -- choosing the minted spec version from WORKFLOW_SPEC_VERSION and a World's inBandFence capability; go-workflow always mints worlds.SpecVersion.
packages/world/src/spec-version.test.ts > requiresNewerWorld > simulates a v4 reader rejecting a compression-era run -- replicates an older SDK release's predicate in JavaScript; there is no older go-workflow reader to simulate.
packages/world/src/spec-version.test.ts > isLegacySpecVersion -- legacy (spec 1) runs of older SDK data; go-workflow keeps no compatibility with old data.
